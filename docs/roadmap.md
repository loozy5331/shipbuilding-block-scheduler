### 1.1.0 (2026-10-20 릴리스)
- three.js 조립 애니메이션: 간트 탑뷰 → 카메라가 기울며 3D, 용접공이 걸어오고 크레인이 블록을 내려놓음, 실제 같은 용접 비드, 선박 이중선체 측면 블록
- 숙련자는 블록 스케줄링에 들어오면 최적 배치로 시작 (직접 고친 배치·초기화한 상태는 덮어쓰지 않음)
- 간트 줄이 재정렬될 때 새 자리로 미끄러지는 애니메이션 (입력 순서 고정안은 시도 후 되돌림)
- 튜토리얼 중에는 상단 단계 탭으로 건너뛰지 않음
- 폴더 정리: 프론트엔드를 `frontend/`로, 회원 DB를 `backend/data/`로
- 버전 관리 도입: 유의적 버전, `CHANGELOG.md`, main에 `vX.Y.Z` 태그
- 로드맵 문서(이 문서), 합쳐진 로컬 브랜치·작업 폴더 정리 (3차 피드백 원본 커밋은 로컬 태그 `archive/feedback-round3-original`로 보관)

### 1.2.0 (2026-10-20 릴리스)
4차 피드백에서 우선순위를 높인 작업.
- 체험하기는 튜토리얼 가이드를 자동으로 띄우지 않음, 결과 평가서 최적 값에 분모 표시("최적 5 / 7개")
- 배치 제외 날짜: 주말·공휴일(2025~2028) 기본 휴무, 간트 날짜 칸을 눌러 작업 불가 지정. 주말·공휴일은 납기를 늦추고 직접 지정한 날은 납기 유지
- 간트 날짜 확장: 모든 블록을 한 줄로 이어도 들어가는 날까지
- 블록 합의(숙련자): 합의한 블록은 그대로 두고 나머지만 재최적화, 블록 표에서도 체크
- 엑셀 선택 열 `자재 납기일`: 입고일부터 착수, 결과에 지연 원인
- 날짜별 날씨 표시(Open-Meteo, 16일 예보)
- e2e: 조립 애니메이션 테스트는 애니메이션 수정 전까지 건너뜀

## 남은 작업

우선순위 순. 애니메이션 확장은 후순위로 미룬다.

### 공휴일 표 갱신
`frontend/src/domain/holidays.ts`는 2028년까지. 해가 바뀌기 전에 월력요항(우주항공청)을 보고 다음 해를 추가한다. 2027년 설날은 자료마다 달라(2/6·2/7) 월력요항 기준 2/7로 넣었다.

### 1. 블록 작업 촬영(OCR)
[ocr-plan.md](ocr-plan.md)의 M0~M5. 시작 전에 정할 것:
1. 찍을 대상: 인쇄된 작업지시서 양식인지, 손글씨·화이트보드가 많은지 → M0에서 실제 사진 20장 이상 수집
2. OCR 서버 위치와 GPU 유무
3. 사진 보관 여부 (기본: 처리 후 바로 삭제)

### 2. (후순위) 간트 위 작업 애니메이션 확장
지금은 결과로 넘어갈 때 대표 블록 하나의 조립을 한 번 보여 준다. 메모의 나머지:
- 작업 날짜가 넘어가면 작업자가 간트의 다음 날짜 칸으로 걸어가 이어서 작업 (표시는 최대 두 명, 블록 양쪽)
- 크레인도 해당 날짜로 바퀴로 이동하며 이어서 작업
- 다른 작업 줄로 넘어갈 때 가까우면 이어서 걷고, 멀면 간트 밖에서 새로 들어와 작업
- 설정의 애니메이션 끄기·`prefers-reduced-motion`을 그대로 따름
